#  Barcode Reader 

This project presents a complete barcode reading pipeline developed using **OpenCV** and classical image processing techniques — without relying on machine learning or deep learning.

The notebook is structured into **three main components**:

1. Detector – Locates barcode regions in input images  
2. Preprocessing Functions – Applies image transformations to enhance barcode visibility  
3. Decoder – Extracts and interprets the barcode patterns into readable data  
4. Helper Functions– Utility methods for visualization, error handling, and I/O

---

## Key Highlights

-  Built entirely with **OpenCV** – no ML/DL frameworks required  
-  Successfully handles various real-world distortions:
  - **Scratches and missing parts**
  - **Brightness and lighting inconsistencies**
  - **Frequency and wave-like distortions**
